TRvACC is the Turkish Virtual Area Control Centre on the [VATSIM](https://www.vatsim.net) network. We cover the **Istanbul FIR (LTBB)** and the **Ankara FIR (LTAA)**, and we provide air traffic control for Turkish airspace, including Istanbul, Sabiha Gökçen, Antalya, and Ankara.

VATSIM Türkiye is facility **TURK** in [VATEUD](https://www.vateud.net), the European division of VATSIM.

## Repositories

Public code and sector data for Turkish airspace lives in this organisation.

| Repository | What it is |
| --- | --- |
| [LTXX-Sector-File](https://github.com/VATSIM-Turkiye/LTXX-Sector-File) | EuroScope plugins, settings, and manuals for the Turkish sector file. These are the files maintained by hand alongside the [AeroNav GNG](https://files.aero-nav.com/LTXX) package. |

Install the full sector file from AeroNav GNG. A GitHub release does not include every file the package needs.

## Contributing

Anyone can contribute to the sector file. Open a pull request on [LTXX-Sector-File](https://github.com/VATSIM-Turkiye/LTXX-Sector-File) and a member of the sector-file team will review it before it is merged.

Bugs, feature suggestions, discussions, and documentation notes belong on the [issue board](https://github.com/VATSIM-Turkiye/LTXX-Sector-File/issues).
